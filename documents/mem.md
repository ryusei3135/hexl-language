# メモリアクセス

本言語では、`[]` を使用することで、変数やアドレスを介してメモリへ直接アクセスできます。

メモリアクセスには、以下の機能があります。

* メモリに格納する型の指定
* 変数のメモリ領域への配置
* 静的領域への変数の配置
* ポインタの作成
* ポインタを使用したメモリへの読み書き
* 配列の読み書き
* `[]` による直接的なメモリアクセス

---

## メモリに入れる型の定義

**変数を定義するときは、必ず値を入れること**

メモリへ値を格納するときは、`[T]` の形式で格納する型を指定します。

```text
var: [T] = value
```

`T` には、メモリへ格納する型を指定します。

例えば、`int` 型の値をメモリへ格納する場合は、

```text
var: [int] = 0
```

となります。

この指定によって、コンパイラはメモリへの読み書きを行う際に、対象となるデータのサイズや解釈方法を決定できます。

---

## 変数のメモリ領域への配置

変数を通常通り宣言した場合、その変数は基本的に**スタック領域へ配置されます**。

```text
stack: [T] = value
```

例えば、

```text
stack: [int] = 0
```

とした場合、`int` 型の値を格納する領域がスタック上に確保されます。

配置先を特別に指定しない場合は、スタック領域がデフォルトの配置先になります。

---

## 静的領域の変数

静的領域へ変数を配置する場合は、`""[T]` を使用します。

```text
static: ""[T] = value
```

例えば、

```text
static: ""[int] = 0
```

は、`int` 型のデータを静的領域へ配置するための指定です。

通常の

```text
var: [int]
```

がスタック領域へ配置されるのに対して、

```text
var: ""[int]
```

のように配置先を指定することで、静的領域へ配置できます。

静的領域に配置されたデータは、関数の実行単位に依存せず、プログラムの実行中に一定のメモリ領域へ配置されます。

---

## ポインタの作成

ポインタは、変数の型に `*` を付けることで宣言できます。

```text
a: int* = [var]
```

この例では、`a` は `int` 型のデータを指すポインタになります。

`[var]` は、対象となる変数のメモリアドレスを取得するために使用します。

つまり、

```text
a: int* = [var]
```

は、

```text
a ← var のアドレス
```

という意味になります。

---

## ポインタによるメモリの読み書き

ポインタを `[]` で囲むと、そのポインタが指しているメモリへアクセスできます。

### 読み込み

```text
a: int* = [var]

value: int = [a]
```

`[a]` は、`a` が保持しているアドレスを使用してメモリから値を読み込みます。

### 書き込み

```text
a: int* = [var]

[a] = 10
```

この場合、`a` が指しているメモリへ `10` を書き込みます。

---

## `[]` によるメモリアクセス

本言語では、`[]` で囲まれた式を**メモリアクセス式**として扱います。

```text
[expression]
```

`expression` が示すアドレスを使用して、そのメモリへアクセスします。

例えば、

```text
[a]
```

では、`a` が保持するアドレスを使用します。

メモリから値を取得する場合：

```text
value = [a]
```

メモリへ値を書き込む場合：

```text
[a] = value
```

この構文により、通常の変数アクセスとメモリへの直接アクセスを明確に区別できます。

---

## 配列の読み書き

配列では、インデックスを指定することで特定の要素へアクセスできます。

```text
[var index]
```

`var` は配列、`index` はアクセスする要素の番号です。

例えば、

```text
[var 0]
```

は配列の先頭要素へアクセスします。

```text
[var 2]
```

は3番目の要素へアクセスします。

### 読み込み

```text
value: int = [var index]
```

指定されたインデックスの要素を読み込みます。

### 書き込み

```text
[var index] = 10
```

指定されたインデックスの要素へ `10` を書き込みます。

---

## メモリ領域

変数の配置先は、宣言方法によって決まります。

| 宣言              | 配置先            |
| --------------- | -------------- |
| `var: [T]`      | スタック領域         |
| `var: ""[T]`    | 静的領域           |
| `a: T* = [var]` | `var` のアドレスを取得 |

配置先を明示しない通常の変数は、スタック領域へ配置されます。

---

## メモリアクセスの考え方

`[]` は単なる配列アクセス専用の構文ではなく、**メモリへアクセスするための基本構文**です。

そのため、

```text
[a]
```

```text
[var index]
```

のような構文は、どちらも本質的には「指定された場所のメモリへアクセスする」という同じ仕組みで処理されます。

これにより、ポインタ、配列、スタック領域、静的領域などを同じメモリアクセス機構で扱うことができます。

---

## 構文一覧

| 構文            | 用途              |
| ------------- | --------------- |
| `[T]`         | メモリへ格納する型の指定    |
| `var: [T]`    | スタック領域へ変数を配置    |
| `var: ""[T]`  | 静的領域へ変数を配置      |
| `a: T*`       | `T` 型へのポインタ     |
| `[var]`       | 変数のアドレスを取得      |
| `[ptr]`       | ポインタが指すメモリへアクセス |
| `[var index]` | 配列要素へアクセス       |
| `[expr]`      | 式が示すメモリへアクセス    |

---

## まとめ

本言語のメモリアクセスは、`[]` を中心として設計されています。

```text
var: [T]        スタック領域へ配置
var: ""[T]      静的領域へ配置
[var]           アドレス取得
[ptr]           ポインタ経由のアクセス
[var index]     配列アクセス
```

配置先を指定しない場合はスタック領域を使用し、必要に応じて静的領域などの別の配置方法を指定できます。

`[]` による統一された構文によって、配列アクセスからポインタ操作まで、CPUが持つメモリアクセス機能を直接的に表現できます。
