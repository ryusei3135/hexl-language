# match式について
`match` は条件分岐を行うための式です。

与えるものによって3種類の使い方があります。

- 真偽値(Boolean)を与える
    - `if` と同じような単純な条件分岐になります。
- 値を与える
    - その値を各パターンと比較し、一致した処理を実行します。
    - 他のプログラミング言語の `switch` や `match` に相当します。
- 何も与えない
    - 各条件を上から順番に評価し、最初に真になった処理を実行します。
    - `if` / `else if` / `else` の連続と同じように利用できます。

1. Booleanを与える

    `match` の後ろに真偽値の式を書くと、その結果によって処理が分岐します。
    ```
    match a == 10 {
        // a が 10 のとき
    } | {
        // それ以外
    }
    ```
    これは次の if と同じ意味です。
    ```
    if (a == 10) {
        //
    } else {
        //
    }
    ```
    `Boolean`を渡す場合は、単純な2択の条件分岐に適しています。

2. 値を与える

    `match` の後ろに値を書くと、その値を各パターンと比較します。
    ```
    match a {
        10 => {
            // a == 10
        }
        20 => {
            // a == 20
        }
        | => {
            // どれにも一致しない
        }
    }
    ```
    これは概ね次のような処理になります。
    ```
    if (a == 10) {
        //
    } else if (a == 20) {
        //
    } else {
        //
    }
    ````
    複数の値を比較したい場合はこちらを使用します。

3. 値を与えない

    `match` の後ろを空にすると、各ブロックに条件式を書きます。
    ```
    match {
        a == 10 => {
            //
        }
        a > 5 =>  {
            //
        }
        b == 0 => {
            //
        }
        |  => {
            //
        }
    }
    ```
    各条件は上から順番に評価され、最初に真になったブロックだけが実行されます。

    これは次の `if` / `else if` と同じ動作です。
    ```
    if (a == 10) {
        //
    } else if (a > 5) {
        //
    } else if (b == 0) {
        //
    } else {
        //
    }
    ```
    複雑な条件分岐を一つの match にまとめたい場合に利用します。

## 使い負け

| 書き方 | 用途 | ほかの言語では |
| --- | --- | --- |
| match 条件式 | 二択 | `if` |
| match 値 | 値の一致判定 | `match` / `switch` |
| match | 条件を順番に | `if` / `if else` |
