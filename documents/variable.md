# 変数の定義や使い方について

## 定義方法
1. 普通の変数の定義
2. スタック領域の変数
3. 静的領域の変数
4. 配列の変数
```
d: ty = value
a: [int] = 10
b: ""[int] = 10
c: [int 4] = {1, 2, 3, 4}
```
- 変数名: 型 = 値

## メモリに配置
- 型を[]で囲むことで、スタック領域に強制的に配置
- []の前に""をつけると、静的領域になる
```
a: [int] = 10
b: ""[int] = 20
```
### 配列
```
a: [int 3] = {0, 1, 2}
b: [int 5] = {0}
```
- `a`このように`[]`の中に、型と長さを指定するとスタック領域に配列
ができる
- `b`のように初期化すると配列の値が任意の値になる

## ポインタ
- 変数を[]で囲むとアドレスを取得することができる
- 型に*をつけるとポインタ型にすることができる
```
a: int = 10
b: int* = [a]
```
- 変数に`[]`をつけるとポインタの先の値を変更することができる
- なにもつけない場合はアドレスそのものを変更する
```
[a] = 10
```
