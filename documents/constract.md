# 契約について

契約（Contract）は、ある値に対して「特定の処理が行われるまで、その値を一定の規則に従って扱わなければならない」という制約をコンパイル時に付与する機能である。

契約は特に、動的に確保したメモリなどの**解放や後処理の忘れ**を防止するために使用する。

契約の検査はコンパイル時に行われるため、実行時の管理機構を必要としない。

## 基本構文

契約は型の後ろに `must` と終了関数を記述する。

```text
a: int* must=free = malloc(...)
```

この例では、`a` は `free` によって契約を終了させなければならない。

```text
free(a)
```

`free(a)` が実行されると、`a` に付与された契約は終了する。

契約が終了しないまま、その値の有効範囲を抜ける場合はコンパイルエラーとなる。

## 契約の目的

契約は主に、以下のような処理の完了をコンパイル時に保証するために使用する。

* メモリの解放
* リソースの解放
* 特定の後処理
* 所有している値の消費
* 特定の関数による処理

例えば、メモリを確保する関数がポインタに契約を付与して返すことができる。

```text
func malloc(...): int* must=free
```

この関数の戻り値を受け取った場合、呼び出し側はその値を `free` に渡す必要がある。

```text
a: int* = malloc(...)

free(a)
```

契約を終了しない場合、

```text
a: int* = malloc(...)
```

のようなコードはコンパイルエラーとなる。

## 契約の終了

契約は、契約に指定された関数へ値を渡すことで終了する。

```text
a: int* must free = malloc(...)

free(a)
```

契約を終了させる関数は、契約対象となる値を引数として受け取る。

契約の終了処理が完了した時点で、その値に付与されていた契約は終了する。

## `of`

契約を終了させる関数には、`of` を使用して終了対象となる契約を指定できる。

```text
func free(a: int* of free)
```

`of` は、その引数によってどの契約を終了させるのかを表す。

例えば、

```text
a: int* must=free = malloc(...)

free(a)
```

では、`free` の引数 `a` が `a` 自身の `free` 契約を終了させる。

## 契約中の値

契約が存在している値には、通常の値とは異なる制約が適用される。

契約は、その値に必要な処理が完了するまで維持される。

### 再代入

契約中の変数への再代入は禁止する。

```text
a: int* must=free = malloc(...)

a = ...
```

このコードはコンパイルエラーとなる。

契約対象の値を別の値で上書きすると、元の契約を終了させる対象を失うためである。

契約を終了した後であれば、通常の再代入が可能になる。

```text
a: int* must=free = malloc(...)

free(a)

a = ...
```

## `move`

契約中の値を `move` によって別の場所へ移動する場合、契約も同時に移動する。

ただし、契約で指定された終了関数を呼び出す前に、契約対象の値を `move` して契約を終了できなくすることは禁止する。

例えば、

```text
a: int* must=free = malloc(...)

b = move a
```

のようにして契約を放棄することはできない。

契約対象の値は、最終的に指定された終了関数へ渡されなければならない。

## 契約と参照

契約中の値から参照を作成することができる。

ただし、参照によって契約そのものを移動したり、終了したりすることはできない。

例えば、

```text
a: int* must free = malloc(...)

b: int& = a
```

のような不変参照を作成できる。

この参照は `a` の契約を所有しない。

したがって、

```text
free(a)
```

によって `a` の契約が終了すると、それに関連する参照も使用できなくなる。

## 契約とポインタ

ポインタ型の値に契約を付与することができる。

```text
a: int* must free = malloc(...)
```

ポインタそのものが契約対象となる。

契約中のポインタから作成できるものは制限される。

* ポインタの位置
* ポインタが指す値
* 不変参照

など、元の契約を破壊しない操作のみを許可する。

契約中のポインタを利用して、別の所有権を生成することは禁止する。

## 契約と可変参照

契約対象の値から可変参照を作成する場合、その可変参照によって契約対象の値を失うことがないようにする。

契約対象の値は、契約終了まで必ず追跡可能でなければならない。

## 契約の生存期間

契約は、以下のいずれかによって終了する。

1. 指定された終了関数が呼び出される
2. 契約を保持する構造体などの契約が終了する

契約中の変数がスコープを抜ける場合、契約が終了していなければコンパイルエラーとなる。

```text
{
    a: int* must free = malloc(...)
}
```

この場合、`free(a)` が存在しないためエラーとなる。

## ネストしたスコープ

契約は、値の所有状態とともにスコープを越えて移動できる。

ただし、契約終了時には、その契約から生成された参照なども有効ではなくなる。

```text
{
    a: int* must free = malloc(...)

    {
        b: int& = a
        ...
    }

    free(a)
}
```

この場合、`b` は `a` の契約を所有しない。

## 構造体と契約

構造体そのものに契約を付与することができる。

```text
struct A: must {
    p: int* must=free
}
```

構造体が契約を持つ場合、その契約は構造体全体に対して適用される。

構造体内部の契約対象を個別に管理するのではなく、構造体自身を契約対象として扱う。

また、1つの構造体に対して複数の契約対象を持たせることは制限する。

## 配列と契約

契約を持つ値を配列に格納する場合、配列内の契約をすべて追跡できなければならない。

契約中の値を含む配列を、そのまま破棄することは禁止する。

例えば、

```text
a: [int* must=free 5]
```

のような配列では、配列の各要素について契約が存在する。

そのため、配列を破棄する前にすべての契約を終了させなければならない。

```text
must const i = 0..a {
    free([a i])
}
```

すべての要素について契約が終了した後、配列を破棄できる。

## 契約の原則

契約機能では、以下を基本原則とする。

1. 契約はコンパイル時に検査する。
2. 契約対象の値は、指定された終了処理を必ず受ける。
3. 契約中の変数を再代入してはならない。
4. `move` によって契約を失うことはできない。
5. 契約対象から作成された参照は、契約を所有しない。
6. 契約が終了した場合、その契約に依存する参照は使用できない。
7. スコープ終了時に契約が残っている場合はコンパイルエラーとする。
8. 契約は実行時のガベージコレクションではなく、コンパイル時の静的検査によって安全性を確保する。
