# 構造体・列挙型について

## 構造体

構造体は、複数のメンバをまとめて1つの型として扱うための機能です。

### 定義方法

```text
struct Name {
    mem: int
    mem2: int
}
```

`struct` の後に構造体名を指定し、`{}` の中にメンバを定義します。

各メンバは、

```text
name: ty
```

の形式で定義します。

### 初期化方法

構造体は、構造体名と各メンバを指定して初期化します。

```text
a: Name = Name {
    mem: 1
    mem2: 10
}
```

---

## 構造体のメソッド

構造体には、通常の関数とは別に**メソッド**を定義できます。

メソッドは構造体に属する関数であり、構造体のインスタンスから呼び出すことができます。

### 関数の定義方法

通常の関数は以下の形式で定義します。

```text
name(arg: ty, ..): ty {
    ..
}
```

例えば、

```text
add(a: int, b: int): int {
    return a + b
}
```

のように定義できます。

### 自身へのアクセス

構造体のメソッドでは、`self` を使用して現在のインスタンス自身へアクセスできます。

```text
method(self: Self, arg: ty, ..): Self {
    ..
}
```

`Self` は、現在メソッドを定義している構造体自身の型を表します。

例えば、

```text
struct Name {
    value: int

    add(self: Self, value: int): Self {
        self.value = self.value + value
        return self
    }
}
```

のように定義できます。

`self` はメソッドを呼び出したインスタンスを表します。

---

### メソッドの呼び出し

構造体をインスタンス化した後、`.` を使用してメソッドへアクセスできます。

```text
a: Name = Name {
    value: 10
}

a.add(5)
```

このとき、

```text
a.add(5)
```

は `a` を `self` としてメソッドを呼び出します。

---

## 構造体の初期化メソッド

構造体には `new` という名前のメソッドを定義できます。

`new` が定義されている場合、`::new()` を使用して構造体を初期化できます。

### `new` の定義

```text
new(): Self {
    ..
}
```

例えば、

```text
struct Name {
    value: int

    new(): Self {
        return Self {
            value: 0
        }
    }
}
```

### `new` による初期化

```text
a: Name = Name::new()
```

`Name::new()` は、`Name` に定義された `new` メソッドを呼び出してインスタンスを生成します。

`new` が定義されていない場合は、この方法で初期化することはできません。

---

## メソッドへのアクセス方法

構造体のメソッドには、主に2種類のアクセス方法があります。

### 型からアクセス

`::` を使用して、構造体に属するメソッドへアクセスします。

```text
Name::new()
```

これは構造体そのものからメソッドを呼び出す方法です。

特に `new` のような、インスタンスを必要としない初期化処理に使用できます。

### インスタンスからアクセス

`.` を使用して、インスタンス化された構造体からメソッドへアクセスします。

```text
a.func()
```

例えば、

```text
a: Name = Name::new()

a.func()
```

のように使用します。

この場合、`a` がメソッドの `self` として渡されます。

---

## 列挙型

列挙型は、複数の選択肢を1つの型として表現するための機能です。

### 定義方法

```text
enum Name {
    Mem
    Mem2
}
```

`enum` の後に列挙型の名前を指定し、`{}` の中にメンバを定義します。

この例では、`Name` 型には `Mem` と `Mem2` の2つの値があります。

### 初期化方法

列挙型は `::` を使用して値を指定します。

```text
a: Name = Name::Mem
```

`Name::Mem` は、`Name` 型の `Mem` を表します。

---

## 構造体と列挙型の違い

構造体と列挙型はどちらも新しい型を定義する機能ですが、メソッドに関する仕様が異なります。

| 機能              | 構造体 | 列挙型 |
| --------------- | :-: | :-: |
| メンバを持つ          |  ○  |  ○  |
| インスタンス化         |  ○  |  ○  |
| メソッドを定義         |  ○  |  ×  |
| `self` を使用      |  ○  |  ×  |
| `Self` を使用      |  ○  |  ×  |
| `::new()`       |  ○  |  ×  |
| `.` によるメソッドアクセス |  ○  |  ×  |

**メソッドを定義できるのは構造体のみです。**

そのため、構造体では

```text
Name::new()
a.func()
```

のようなアクセスが可能ですが、列挙型ではメソッドを定義することはできません。
