
# インラインアセンブラの使い方について
- 使い方
    - `#asm`プロプロセッサを使う
    - `アセンブラの名前`は`asm_fmts/`や`asm.json`で設定された物
    ```
    #asm(アセンブラの名前) {
        ..
    }
    ```

## 埋め込み機能
- `{space}`は展開時に空白を挿入
- `${..}`この中に変数を代入可能

```
#asm(gcc_x64) {
    "{space}mov ${a}, %eax"
}
```

## 展開されるときの仕様 
- インラインアセンブラが展開されるときには、
`埋め込み機能`が処理されたあとに、そのまま展開されます。
- 展開される前に使用中のレジスタがpushされ、終了したらpopされる
