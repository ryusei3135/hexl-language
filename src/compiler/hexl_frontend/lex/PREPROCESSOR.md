# プリプロセッサ(`preprocessor.rs`)

## `#define`
### 値のマクロ
```
#define A 10
ret #A + 1      // ret 10 + 1
```

### 関数形式マクロ(2026-10-11)
```
#define Name(arg, arg2, ..) BODY
#define SET(a, b) (a = b + 1)

#SET(x, 2)      // (x = 2 + 1)
```
- 書き方
    - `#define`の名前の**直後(空白なし)**に`(`を書くと関数形式になる。
        `#define A (1)`のように空白があれば、従来どおり値のマクロ(`A`→`(1)`)。
    - 仮引数は識別子をカンマ区切りで書く。`()`(引数なし)も可。
        識別子でない・重複している・`)`が無い場合は`panic`する。
    - 定義は1行で書く。`BODY`は、`)`の後ろから行末まで(前後の空白は除く)。
- 呼び出し
    - `#Name(a, b)`と書く(値のマクロの`#A`と同じく`#`を付ける)。`(`は名前の直後に書く。
    - 実引数は、括弧(`()` `[]` `{}`)の外側の`,`で区切る。
        `#ADD(f(1, 2), 3)`の実引数は`f(1, 2)`と`3`の2つ。
        文字列リテラル(`"a,b"`)の中の`,`や括弧は区切りとして扱わない。
    - 実引数の前後の空白は取り除く。複数行にまたがってもよい
        (後続の行番号(`#line`、トークンの行)がずれないよう、読み飛ばした改行は展開結果の後ろに出す)。
    - 実引数の数が仮引数の数と違う、`(`が無い、`)`で閉じていない場合は`panic`する。
- 展開の手順(`expand_fn_macro`)
    1. 実引数の中の`#NAME`を先に展開する(`#ID(#A)`なら`#A`が先に展開される)。
    2. `BODY`の中の仮引数(識別子単位)を、実引数のテキストに置き換える。
        - 文字列リテラルの中は置き換えない(`"a"`の`a`はそのまま)。
        - 数字で始まる語(`2a`)は置き換えない。
    3. 置き換えた結果の中の`#NAME`/`#NAME(..)`を展開する(マクロから別のマクロを呼べる)。
        展開が64段を超える(自己再帰など)と`panic`する(`MAX_EXPAND_DEPTH`)。
- 注意
    - 展開は**テキストの置き換え**で、式としての括弧は自動で付かない。
        `#define MUL(a, b) a * b`に`#MUL(1 + 2, 3)`を渡すと`1 + 2 * 3`になる。
        必要なら`BODY`側で`(a) * (b)`のように括弧を付ける。
    - 同名の再定義は無視される(値のマクロと同じ)。
    - `#if #NAME`は、関数形式マクロも「定義済み」として扱う。
    - 値のマクロの値は、従来どおり再展開しない(`#define B #A`の`#A`はそのまま残る)。

### 複数行の`#define`(2026-10-11)
```
#define N {{
  expr = 10
  expr2 = 10
}}

#N              // expr = 10
                // expr2 = 10
```
- 本体を`{{`と`}}`で囲むと、複数行にまたがって書ける。値のマクロにも、関数形式マクロにも使える。
    ```
    #define SET(a, b) {{
      a = b
      a = a + 1
    }}
    ```
- 本体は`{{`と**最初の`}}`**の間。本体の前後の空白・改行は取り除き、途中の改行とインデントはそのまま残す。
    `{{ 1 }}`のように1行で書いてもよい(本体は`1`)。
- `{{`は名前(または`NAME(args..)`)と同じ行に書く。`}}`の後ろには、同じ行に何も書けない。
- 本体の中に`}}`を書きたいときは、`} }`のように空白を入れる(`{ loop { x }}`のような入れ子の`}}`で
    閉じてしまうため)。文字列リテラルの中の`}}`も閉じる印として扱う。
- `}}`で閉じていない、`}}`の後ろに文字がある場合は`panic`する。
- 無効な`#if`の中の複数行の定義は、まるごと読み飛ばす。
- 行番号
    - 定義が読み飛ばした改行は、定義の位置にそのまま出すので、定義より後ろの行番号はずれない。
    - 呼び出した場所には本体の改行も含めて展開されるので、**呼び出しより後ろの行番号は、
        本体の改行の数だけ後ろへずれる**(`#line`やトークンの行番号)。
- 従来の`#define A { x }`(`{{`で始まらない値)はそのまま値として使える。
    ただし`#define A {{1}}`のように`{{`で始まる値は、`{{`と`}}`を外した`1`になる。

## 条件付きコンパイル(`#if` / `#elif` / `#else` / `#endif`)
```
#if #windows
  ret 1
#elif #linux
  ret 2
#else
  ret 3
#endif
```
- 条件は`#NAME`の形で書き、`NAME`が定義済みなら成り立つ。上から順に調べ、**最初に成り立った枝だけ**が有効になる。
- `#elif`は何個でも書ける。`#else`は省略可、入れ子も可。`#else`の後ろに`#elif`を書くと`panic`する。
- 組み込みのOSシンボル`#linux` / `#windows`は、`--linux` / `--windows`で選んだOS(未指定なら実行環境のOS)の
  **1つだけ**が定義される。もう一方は未定義(`Lexer::with_os(os)` → `Preprocessor::setup_defines_for(os)`)。

## `#include "file"` のインライン展開
```
#include "test.hexl"         // ここで読み込み、その場に展開する
#include "test.hexl"::io     // 展開しない(後段が処理する)
#include io="test.hexl"      // 展開しない(後段が処理する)
```
- 別名のない1番目の形だけを、プリプロセッサがファイルを読み込んで、その場に展開する。
  `"file"`の後ろは、空白か`//`のコメントだけ書ける。
- 相対パスは、`#include`を書いたファイルのあるディレクトリが基準(入れ子でも、そのファイルの場所が基準)。
  基準は`Lexer::set_source_file`で教える(`lib.rs`の`build`が呼ぶ)。
- 取り込んだファイルもプリプロセッサを通る(`#if`などが使える)。そこで`#define`したものは、以降のソースでも使える。
  `#if`の状態は、取り込んだファイルの中で閉じる。
- 無効な`#if`の枝の中の`#include`は、読み込まない(ファイルが無くてもよい)。
- ファイルが開けない、`#include`が循環している(自分自身を含む)場合は`panic`する。
- 同じファイルを2回`#include`すると、2回ともそのまま展開される(重複した定義は呼び出し側で避ける)。
- 行番号: 展開した分だけ、`#include`より後ろの行番号(`#line`、トークンの行)が後ろへずれる。

## 実装の場所
| 処理 | 関数 |
|------|------|
| `#define`の読み取り(値/関数形式の判定) | `sort_preproc` → `parse_define_fn` |
| 複数行の`#define`(`{{ .. }}`)の読み取り | `read_multiline_define` / `is_define_header` |
| 呼び出しの実引数の読み取り | `parse_macro_args` |
| 仮引数の置き換え | `substitute_params` |
| 展開(実引数→置き換え→再展開) | `Preprocessor::expand_fn_macro` / `expand_inline` |
| `#include "file"`の判定/読み込み | `plain_include_path` / `Preprocessor::include_inline` |
| ソース全体の処理(行頭の`#define`/`#if`、インライン展開) | `Preprocessor::preprocess` |

## コメント(2026-10-22)
```
ret 1 // 行末までがコメント
/* 複数行にも
   またがれる */
ret /* 途中にも書ける */ 2
```
- `//`は行末まで、`/* */`は`*/`までがコメントになる(入れ子は不可)。
- 字句解析より前(`preprocess_text`の先頭、`comment.rs`の`strip_comments`)で取り除くので、
  `#define A 10 // 値`や`#if #A // 条件`、`#include`で取り込んだファイルの中のコメントも消える。
- コメント内の改行は残す(行番号はずれない)。`/* */`は空白1つになる(`a/**/b`は`a b`)。
- 文字列リテラル(`"a//b"`)の中の`//`・`/*`はコメントではない。
- 閉じていない`/*`は、ソースの末尾までがコメントになる。
